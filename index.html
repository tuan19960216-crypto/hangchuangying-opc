怎么生成 Token？（给同事看的步骤）
  1. 用一个已被加为本仓库 协作者（Collaborator）的 GitHub 账号登录，打开 github.com/settings/personal-access-tokens/new
  2. Token name 随便写，如 opc-site；Expiration 选 1 年
  3. Repository access 选 Only select repositories，勾选
  4. Permissions → Repository permissions → Contents 选 Read and write（其他都不用）
  5. 点 Generate token，复制以 github_pat_ 开头的一串，粘贴到上面
仓库主人（tuan19960216-crypto）要先在仓库 Settings → Collaborators 里把同事加进来，同事才能生成有写入权限的 Token。
