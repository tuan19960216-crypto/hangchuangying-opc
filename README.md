# 杭创营OPC社区 · 工地日志与来访档案

网站地址：https://tuan19960216-crypto.github.io/hangchuangying-opc/

- `index.html` — 整个网站（展示、发布、下载都在这一个文件里）
- `data/posts.json` — 所有内容的索引（发布时由网页自动更新）
- `images/<内容id>/` — 照片（发布时由网页自动上传，已压缩到长边 1600px）

## 怎么发布

打开网站 → 右上角「设置」→ 填名字和 GitHub Token → 「＋ 发布」。
Token 生成步骤在网站的「设置」弹窗里有写。同事需要先被加为本仓库的 Collaborator（Settings → Collaborators）。

## 怎么下载给公众号

- 每篇内容：「复制文案」直接粘贴到公众号编辑器；「打包 zip」得到照片 + 文案 txt。
- 右上角「批量打包」：按日期范围导出一周/一段时间的全部内容。
